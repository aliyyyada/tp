# Скачать офлайн-комплект

1. Скачайте ZIP этой ветки: https://github.com/aliyyyada/tp/archive/refs/heads/offline-kit.zip
2. Распакуйте ZIP целиком (на диске понадобится около 600 МБ).
3. В распакованной папке запустите ASSEMBLE.cmd. Он соберёт tp-offline-win11-py311.zip из частей и проверит SHA256. Интернет для сборки не нужен.
4. Распакуйте полученный tp-offline-win11-py311.zip в отдельную папку и следуйте README.md внутри: установите Python 3.11 x64 и Tesseract из installers, затем запустите install_offline.cmd.

Файлы part001…part005 — части одного ZIP; отдельно они не открываются. В комплекте все зависимости и модели для CPU, CUDA не нужна. Рукопись текущая версия распознаёт плохо; подробности ниже.

# ТП OCR — офлайн-прототип

Распознавание сканов технологических карт на русском и английском, без фронтенда и сетевых запросов во время работы. Базовый движок Tesseract 5 (CPU), OpenCV, PyMuPDF. GTX 1070 не используется; CUDA не требуется. Это стартовая измеримая база, не готовый распознаватель рукописи. Рукописные записи, бледные штампы и сложный порядок чтения таблиц требуют ручной проверки. Извлечение полей, Excel, ML-разметка таблиц и обучение в этот этап не входят.

## Windows 11 x64: установка без интернета

1. Распакуйте `tp-offline-win11-py311.zip` целиком в каталог, например `C:\tp`.
2. Если у вас нет **Python 3.11 x64**, запустите `installers\python-3.11.9-amd64.exe`. Можно установить рядом с вашей версией Python; включите Python Launcher. Библиотеки в архиве рассчитаны именно на 3.11 x64.
3. Запустите `installers\tesseract.exe` (Tesseract 5.4, Windows x64). Используйте стандартный путь `C:\Program Files\Tesseract-OCR`. Отключите скачивание дополнительных языков: модели уже есть в `tessdata`. Сам установщик сторонний; на Windows в данной среде не проверялся.
4. Запустите `install_offline.cmd` из cmd. Он создаст окружение и установит библиотеки из `wheels` с `--no-index`.
5. Выполните команды ниже из папки проекта. Исходный PDF положите рядом самостоятельно.

```bat
.venv\Scripts\python tpocr.py ocr "312-86 копия ТП.pdf" -o results --tessdata tessdata --auto-rotate
```

Для первоначальной проверки отдельных страниц:

```bat
.venv\Scripts\python tpocr.py ocr "312-86 копия ТП.pdf" -o results --pages 1,2,4 --tessdata tessdata --rotate-page 1:90 --rotate-page 2:90 --rotate-page 4:90
```

Повороты задаются по часовой стрелке. OSD может ошибаться на бледных листах и рукописи: просмотрите PNG и задайте `--rotate-page номер:угол`. Номера страниц с 1. Выходная папка должна быть новой для каждого эксперимента (файлы перезаписываются). `--psm 6` подходит для одного блока, `--psm 11` для разрозненных надписей; по умолчанию PSM 3. `--remove-lines` удаляет длинные линии таблиц, но может повредить буквы: применяйте только после сравнения метрик. `--no-deskew` отключает выравнивание. Коррекция перспективы и восстановление утраченных чернил не реализованы.

## Результат

`result.json` содержит страницы, текст, слова, confidence, координаты и предупреждения. PNG — обработанные страницы, TSV — необработанный результат Tesseract, TXT — текст в порядке блоков OCR. Координаты соответствуют обработанному PNG после поворота и выравнивания; это не координаты исходного PDF. Confidence — внутренняя оценка движка, **не процент верно распознанного текста**. Порядок чтения в сложных таблицах может отличаться от ожидаемого.

## Честная оценка точности

1. Скопируйте `reference.template.json` в `reference.json`.
2. Вручную перепишите весь видимый текст выбранных страниц в `text`, зафиксировав порядок чтения. Сверьте по исходному изображению, затем поставьте `verified: true`. Не используйте результат OCR как непроверенный эталон. Для нечитаемых участков заранее согласуйте единое правило разметки; выбор только читаемых листов завысит оценку.
3. Запустите:

```bat
.venv\Scripts\python tpocr.py evaluate results\result.json reference.json -o metrics.json
```

CER = расстояние Левенштейна по символам / число эталонных символов. WER — то же по словам. Меньше — лучше, 0 означает совпадение. Вставки могут дать больше 100% ошибок. Итог взвешен по длине эталона; есть метрики по страницам. Пробелы нормализуются всегда; `--relaxed` дополнительно игнорирует регистр и ё/е. Пунктуация сохраняется. Полностью пустые эталоны запрещены. Проверяются только страницы, перечисленные в эталоне; это должно быть отражено в отчёте. Для оценки всего документа размечайте все 19 страниц, для выбора движка — репрезентативный набор разных типов страниц. Нельзя объявлять точность всего PDF по отдельным удачным фрагментам.

## Разработка

```sh
python -m unittest -v
```

На Linux установите Tesseract системным пакетным менеджером, Python-зависимости из requirements.txt и укажите `--tessdata`. Код не скачивает модели. На первом этапе рекомендуется сравнить исходный вариант и удаление линий на одном эталоне. Если CER неприемлем, следующим отдельным этапом сравнить нейросетевой OCR русской рукописи на этом же эталоне с проверкой совместимости Pascal/GTX1070.
